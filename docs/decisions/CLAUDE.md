# docs/decisions — ADRs

A changed decision is a **new** ADR that supersedes the old one (the old one's Status line points
forward); existing ADRs are never edited or deleted. Product-level choices (which app, which
setting value) belong in `docs/plan/PRD-001-envsetup.md`, not here. Write the ADR in the same PR as
the change that decides it; template and index in `README.md`.
