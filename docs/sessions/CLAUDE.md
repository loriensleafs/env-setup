# docs/sessions — the session log

Entries are appended by `bun run session` (skeletons with a line per touched file) and filled by
hand; the number, order and the release markers are the script's — never hand-numbered or
reordered. `bun run session -- --new <slug>` only at a real session start; `--check` before the
`docs(session): …` commit. The Narrative is written as things happen. Rules and template in `README.md`.
